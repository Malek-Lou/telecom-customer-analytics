# Notice

This repository is a public portfolio version of a customer analytics project developed during an internship in the telecommunications sector.

## Confidentiality

The original project was developed using confidential company data.

This repository does **not** contain:

- the original company dataset;
- real customer records or identifiers;
- personally identifiable information;
- confidential customer-level results;
- internal company documents;
- proprietary business information;
- real company performance metrics;
- or dashboard exports generated from confidential internship data.

## Synthetic Demonstration Data

The files contained in `demo_data/` are **fully synthetic** and were created exclusively to demonstrate the functionality of the code and Streamlit dashboard.

They are not derived from, sampled from, or intended to reproduce the confidential internship dataset.

Any customer identifiers, offers, values, churn probabilities, model scores, feature importances, or other results shown in the public demo are artificial.

The model-performance values displayed in the synthetic demonstration are illustrative and should not be interpreted as results obtained during the original internship.

## Screenshots

Images contained in `assets/` were generated using the synthetic demonstration data.

They do not display confidential company or customer information.

## Purpose

This repository is intended to showcase the methodology, code structure, data-science workflow, and dashboard developed as part of the project.

It is provided for portfolio and educational purposes and is not intended to reproduce the company's internal analysis or production environment.
